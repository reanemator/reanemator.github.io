Что нужно для работы

Приложение открывается сразу с демо-данными. Чтобы видеть свою статистику, нужен аккаунт Яндекса, подключённый к Рекламной сети Яндекса (РСЯ): нажмите «Подключить кабинет РСЯ».

Частые вопросы

Подключил кабинет, но данные не загружаются

Проверьте, что аккаунт подключён к РСЯ и в его кабинете partner.yandex.ru есть статистика. Если при подключении вы не дали доступ к API партнёрского интерфейса, отключите кабинет и подключите снова.

«Слишком много запросов» или «Ошибка сервера»

Яндекс ограничивает частоту запросов к API. Подождите минуту и потяните экран вниз, чтобы обновить.

Не загружаются данные за длинный период

Яндекс иногда временно ограничивает длину периода в отчётах. Попробуйте период короче.

Как отключить кабинет

«Настройки → Отключить кабинет».

Как удалить данные

Приложение не создаёт своих аккаунтов и не хранит данные на сервере. В приложении откройте «Настройки → Удалить данные»:

  • «Удалить все данные из приложения» — удаляет все подключённые кабинеты, токены и настройки с устройства;
  • отозвать доступ приложения — на странице Яндекс ID → Доступы к данным;
  • удалить сам аккаунт Яндекса (необязательно) — Яндекс ID → Данные → «Удалить аккаунт».

Как сменить язык

«Настройки → Язык». По умолчанию выбирается язык системы.

Политика конфиденциальности

Requirements

The app opens right away with demo data. To see your own statistics you need a Yandex account connected to the Yandex Advertising Network (YAN): tap “Connect YAN data”.

FAQ

I connected my data, but nothing loads

Make sure the account is connected to YAN and has statistics at partner.yandex.ru. If you didn't grant access to the Partner API while connecting, disconnect the source and connect it again.

“Too many requests” or “Server error”

Yandex limits how often the API can be called. Wait a minute and pull down to refresh.

Long periods don't load

Yandex sometimes temporarily limits the period length for reports. Try a shorter period.

How do I disconnect my data?

“Settings → Disconnect source”.

How do I delete my data?

The app does not create its own accounts and stores nothing on a server. In the app open “Settings → Delete data”:

  • “Delete all data from the app” removes all connected sources, tokens and settings from the device;
  • revoke the app's access on the Yandex ID → Data access page;
  • delete the Yandex account itself (optional): Yandex ID → Data → “Delete account”.

How do I change the language?

“Settings → Language”. By default the app follows the system language.
